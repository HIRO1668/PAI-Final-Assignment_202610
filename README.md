# 差動二輪型移動ロボットの経路追従シミュレーションと3D可視化

## 1. 概要

本プロジェクトでは，差動二輪型移動ロボットの運動学モデルを用いて，目標経路に沿って移動するロボットの経路追従シミュレーションを実施する．また，シミュレーションによって得られた走行データを用いて，ロボットの移動軌跡や姿勢を3次元的に可視化する．

## 2. 目的

差動二輪型移動ロボットの運動学と経路追従制御について理解を深めるとともに，シミュレーションによる走行結果の可視化を通じて，ロボットの移動特性や制御性能を確認することを目的とする．

## 3. 使用技術

- Python
- NumPy：数値計算および走行データの処理
- Plotly：走行軌跡の3次元可視化およびアニメーション表示
- Google Colab：シミュレーションの実行環境

## 4. シミュレーション内容

本シミュレーションでは，以下の処理を実施する．

1. 差動二輪型移動ロボットの運動学モデルを設定する．
2. 目標経路に対する経路追従制御を実行する．
3. ロボットの位置および姿勢の時間変化を記録する．
4. 走行データを用いてロボットの移動軌跡を可視化する．
5. 3次元アニメーションによって，ロボットの走行過程を確認する．
